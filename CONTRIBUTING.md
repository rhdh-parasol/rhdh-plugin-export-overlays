# Contributing

This is the **rhdh-parasol/rhdh-plugin-export-overlays** playground — a
metadata and automation hub for managing dynamic plugins for Red Hat
Developer Hub (RHDH).

## Proposing a change

1. Fork the repository or create a branch off `main`.
2. Make your changes on the new branch.
3. Open a pull request against `main`.

## Pull request expectations

Every PR must include:

- **A description of what changed and why.** Explain the motivation and
  summarize the approach so reviewers have the context they need.
- **A link to the related issue**, when one exists. Reference it in the
  PR body (e.g., `Closes #123`) so it is tracked and auto-closed on
  merge.

## Getting help

If you are unsure whether a change is appropriate, open an issue first
to discuss the idea before investing time in a PR.
